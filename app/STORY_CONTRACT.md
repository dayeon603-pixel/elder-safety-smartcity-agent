# 영점 「시민 시점」 데모 계약서 (2026-10-24 19:20, Dayeon 요청)

목표: "진짜 도시가 움직이고, 사람이 실제로 보는 화면이 장면 안에 뜬다." /twin 1구역에 **[관제 시점] / [시민 시점]** 토글.
시민 시점 = 실제 관악구 3D(국토부 건물 38,488동, 단순화 금지)에서 한 어르신(시연 인물)을 거리 높이 카메라로 따라간다.

## 정직성 규칙
- 인원 분포 = 실측 (서울 생활인구, 행정동×시간×연령). 개별 점의 이동 경로는 시각화용 → 화면에 "인원 분포: 서울 생활인구 실측 · 이동 경로: 시각화" 표시.
- 시연 인물 = 가상의 1인(라벨 "시연 인물"). 걸음 0.7 m/s(근거 표기). 경로는 실제 보행망, 실제 횡단보도·정류장·AED.
- 신호 녹색시간은 표준데이터 실측값이 있는 횡단보도만. 없으면 "신호 자료 없음"으로 표시하고 지어내지 않는다.
- 낙상은 라이브 웹캠(또는 공개 낙상 영상 실시간 계산)의 실제 감지 이벤트로 트리거. 버튼 트리거는 "버튼 시연"으로 표시.
- 단말·신호·문자 내용은 전부 실제 API 출력(/terminal, /twin/actions, CAP). 훈련 · 발송 안 함.
- 3D 인물 모델: 라이선스 명확한 공개 glTF(예: Khronos glTF-Sample-Assets CesiumMan, CC-BY 4.0) — 출처 표기. AI 생성 모델 금지.

## 프론트 (스토리 담당) — `src/twin/story/` 소유, TwinPage에는 토글 1개만 추가
1. 도시의 움직임: deck.gl TripsLayer — 행정동별 생활인구(시간대) 비례 표본 점들이 실제 보행망 위를 이동(1점 = N명, 범례). 65+ 은 다른 색. 시간 슬라이더와 연동(밤엔 줄어듦). 워커에서 경로 샘플링.
2. 시연 인물 이야기(키보드 S로 시작, 약 60–90초):
   ① 집 → 정류장 걷기(실제 경로, 0.7 m/s, 거리 높이 추적 카메라)
   ② 실제 횡단보도: 머리 위 신호 카운트다운(실측 녹색 N초 vs 0.7 m/s 필요 M초) → 부족하면 "보행신호 연장 권고" 장면 + 신호 연장 반영 시각화(권고·훈련 표시)
   ③ 정류장 도착: 3D 장면 안의 **정류장 안내단말 화면**(실제 /terminal 메시지와 같은 내용, 체감온도 실측) — 휴대폰 단말과 동시 표시
   ④ 낙상(실제 감지 이벤트) → 인물 쓰러짐 → 펄스 → 지금 열린 가장 가까운 AED까지 경로 + 행인(시연) 왕복 시간(실측 거리 ÷ 1.2 m/s) 표시 → 119 접수(시뮬레이터 202) → 단말에 "근처 쓰러진 분" 표시
3. 카메라: 관제 시점 ↔ 시민 시점 부드러운 전환. 60fps 유지(전체 건물).
4. 사람이 보는 화면 3개(장면 안): 신호등 카운트다운, 정류장 단말, 휴대폰 단말(실물) — 셋 다 실제 데이터.
