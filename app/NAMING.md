# 이름 규칙 (2026-10-25, Dayeon 지시: "영점"을 작품명으로 쓰지 않는다)

| 쓰임 | 이전 | 이후 |
|---|---|---|
| 작품명 (표지·헤더·문서 제목) | 영점, 「영점 · 어르신 안전 스마트도시 인프라」 | **고령자 안전 스마트도시 에이전트** |
| 짧은 이름 (공간 부족할 때) | 영점 | **스마트도시 에이전트** 또는 **에이전트** |
| 비교 라벨 (현행 vs 우리) | 영점, 영점 권고, 영점 추천, 영점 OS | **에이전트**, **에이전트 권고**, **에이전트 추천** |
| 그래프 범례 | 영점 | **에이전트** (비교군은 그대로: 특보 규칙, 현행 실버존 등) |
| 엔진·모델 이름 | 영점 엔진, 영점 폭염 위험 모델, 영점 보행망 분석 | **폭염 위험 모델**, **보행망 분석** (출처 표기는 "에이전트 분석") |
| 팀 표기 | 팀 영점 | **팀 영점** (팀 이름으로만 유지: 표지 작성자, 문서 작성자) |
| 화면 헤더 | 영점 · 관악구 디지털 트윈 | **고령자 안전 스마트도시 에이전트 · 관악구 디지털 트윈** |
| 단말 메시지 | 영점 권고(훈련) | **에이전트 권고(훈련)** |

- 코드 식별자·파일 경로·API 필드 이름(`ours`, `zp*` 등)은 바꾸지 않는다. **사람이 읽는 글자만** 바꾼다.
- 테스트가 화면 문구를 비교하면 기대값도 같이 바꾼다.
- "영점"이 남아도 되는 곳: 팀 이름(작성자·표지 팀명), 저장소·폴더 이름.

## 용어 (2026-10-25 추가, Dayeon: "어르신"은 전문 용어가 아니다)
- 모든 사람이 읽는 글자에서 **어르신 → 고령자** (작품명 「고령자 안전 스마트도시 에이전트」 포함). 조사도 맞춘다(어르신께 → 고령자에게, 어르신이 → 고령자가).
- 예외: 고유명사·인용(기사 제목, 기관 시설명, 법령 원문 인용), 실제 사진 캡션 원문.
- 정류장 단말·마을방송처럼 시민에게 직접 하는 안내 문안도 "고령자"로 쓰되, 호칭으로 부르지 않는다(예: "65세 이상은 …하세요").
